# Compositor 简体中文翻译术语库

本术语库供 `zh-cn` 分支本地化使用。翻译策略：**对齐 Adobe Photoshop 官方简体中文版术语**，不自创——目标用户是会用 PS 的人，用熟悉的词零学习成本。

## 风格约定

- 菜单/按钮的省略号用 macOS 规范的全角省略号 `…`（如「新建画布…」），与系统一致。
- 快捷键提示（⌘Z 等）、单位（`px`/`%`/`°`）、文件名（`.comp`）、滤镜专有名词（Bloom、Camera Raw）**保留英文不译**。
- 句子型提示（如 `.help` tooltip）按中文习惯翻译，但保留技术名词原形。
